# Bank-Program
A beginner Java Application with a clickable JOptionPane menu for balance inquiry, deposits, witdrawals and input validation

## Features

- **Show Balance** — View the current account balance.
- **Deposit** — Add money to the account.
- **Withdraw** — Withdraw money while checking available funds.
- **Input Validation** — Reject invalid amounts and non-numeric input.
- **Interactive Menu** — Navigate using clickable buttons.
- **Exit** — Close the program safely.

## Starting Balance

The account starts with a balance of **$300.00**.


## Purpose

The project helps in Java practice, focusing on methods, loops, conditional statements, exception handling, and graphical user interaction using JOptionPane.

## Limitations

- Account data is not saved after the program closes.
- The application is a learning project, not a real banking system.
- It does not connect to a database or process real financial transactions.
